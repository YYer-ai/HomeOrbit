# HomeOrbit 交通可达性与配套分析设计

## 1. 文档状态

- 日期：2026-08-31
- 状态：设计已完成会话内分节确认，等待用户书面审核
- 类型：架构型扩展
- 实施授权：未授权

本文设计在现有湾区离线 PMTiles、ACS 数据、California OSM PBF、Valhalla 镜像和 PostGIS 镜像基础上，增加交通网络展示、真实路网等时圈、人口密度以及当前选点的设施充足度分析。

## 2. 目标与非目标

### 2.1 目标

1. 提供标准地图、交通网图、分析浅色图三种本地底图主题。
2. 用户可在地图点击并拖动起点，分别执行步行或驾车等时圈分析。
3. 通勤等时圈支持 15、30、45、60 分钟单选档位。
4. 提供湾区人口密度图层。
5. 对当前选点执行固定 15 分钟步行设施分析。
6. 支持教育、医疗、日常购物、公园绿地、公共交通站点五类设施的开关和权重调整。
7. 返回原始供给、分项相对分数和用户加权综合指数。
8. 前端、API、路由和空间数据在断开外网后仍可运行。

### 2.2 非目标

1. 首版不实现公共交通等时圈；入口仅显示“建设中”。
2. 驾车等时圈不包含停车、停车可用性或末端步行。
3. 不生成全湾区设施充足度热力图，仅分析当前选点。
4. 不提供地址搜索或地理编码。
5. 不接入实时路况；交通网图表示道路层级和网络结构，不表示实时拥堵。
6. 相对指数不是法规、规划规范或公共服务达标结论。
7. 不增加卫星影像、在线地图 SDK 或其他外网运行依赖。

## 3. 已确认的产品决策

| 项目 | 决策 |
|---|---|
| 底图 | 标准地图、交通网图、分析浅色图，共用同一份本地 PMTiles |
| 起点 | 地图点击设置，可拖动标记更新 |
| 通勤模式 | 步行、驾车可用；公共交通显示“建设中” |
| 驾车定义 | 纯驾车路网可达性，不含停车和末端步行 |
| 时间档位 | 15、30、45、60 分钟单选 |
| 设施范围 | 当前选点的固定 15 分钟纯步行圈 |
| 设施分类 | 教育、医疗、日常购物、公园绿地、公共交通站点 |
| 权重 | 用户可关闭分类并调整权重；默认五类等权 |
| 评分 | 湾区同口径样本的相对分数；综合分为加权指数 |
| 技术路线 | PMTiles＋Valhalla＋PostGIS＋FastAPI |

公共交通站点作为设施供给类别参与步行配套评估，不表示首版已经支持公共交通路线计算。

## 4. 总体架构

### 4.1 PMTiles 地图层

- 复用 `web/public/tiles/bay-area.pmtiles`。
- 三种主题只改变样式、道路突出程度和背景对比度，不复制矢量数据。
- 交通网图重点显示道路等级和轨道线；它不是实时交通或拥堵图。
- 分析图层包括通勤等时圈、15 分钟步行圈、人口密度和圈内设施。

### 4.2 Valhalla 路由层

- 使用 California OSM PBF 构建本地路由图。
- `pedestrian` 用于步行通勤等时圈和固定 15 分钟设施服务范围。
- `auto` 用于纯驾车通勤等时圈。
- 驾车时间采用离线路网属性和 Valhalla 成本模型，不包含实时拥堵。
- 不允许在 Valhalla 失败时退回圆形缓冲区。

### 4.3 PostGIS 空间分析层

- 保存 ACS/Census tract 人口、土地面积和几何。
- 保存从 OSM PBF 提取并清洗的五类设施。
- 保存湾区参考点、原始供需指标、分项基准分布和数据版本。
- 执行等时圈与 tract、设施、公园面的空间相交和聚合。

### 4.4 FastAPI 编排层

- 验证坐标、模式和时间档位。
- 调用 Valhalla 生成通勤或设施步行圈。
- 调用 PostGIS 完成人口和设施统计。
- 返回稳定的 GeoJSON、统计字段、分项分数、数据口径和局部错误状态。

## 5. 前端组件与状态边界

前端按职责拆分，避免继续把全部交互堆入单一地图组件：

- `MapView`：地图实例、起点标记、样式和分析图层生命周期。
- `MapControls`：底图、图层、交通方式和时间档位。
- `AnalysisPanel`：人口、设施、权重、分项分数和综合指数。
- GIS API 客户端：请求取消、响应校验和中文错误映射。

桌面端使用地图左侧控制区和右侧结果面板；移动端结果面板改为底部抽屉。地图拖动过程中不发请求，仅在 `dragend` 后分析。新起点产生时清除旧分析图层并显示加载状态；旧请求必须取消或因请求序号过期而被忽略。

切换底图样式不得改变起点和分析状态。样式完成加载后，前端依据当前状态恢复人口密度、等时圈和设施图层。

## 6. 接口设计

### 6.1 `GET /gis/config`

返回：

- 可用模式：`walking`、`driving`。
- 不可用模式：`public_transit`，状态为 `coming_soon`。
- 时间档位：`15`、`30`、`45`、`60`。
- 五类设施的标识、中文名称和默认等权权重。
- 数据范围、数据年份、生成时间和版本。
- Valhalla、PostGIS、人口密度产物的就绪状态。

### 6.2 `GET /gis/isochrone`

请求参数：

- `lng`、`lat`：湾区覆盖范围内坐标。
- `mode`：`walking` 或 `driving`。
- `minutes`：15、30、45、60 之一。

返回：

- 等时圈 GeoJSON。
- 请求回显、计算模式、分钟数和数据版本。
- `traffic_assumption=static_network_cost`，明确驾车结果不含实时路况。

### 6.3 `POST /gis/site-analysis`

请求体只包含起点坐标。设施分类开关和权重不参与空间查询。

返回：

- 固定 15 分钟步行圈 GeoJSON。
- 圈内估算人口和人口计算说明。
- 五类原始供给指标。
- 圈内设施 GeoJSON。
- 五类 0–100 相对分数或“样本不足”状态。
- 数据年份、版本、局限和评分说明。

前端使用已返回的五类分项分数，根据启用项和用户权重计算综合指数，因此权重变化不重复调用 Valhalla 或 PostGIS。

### 6.4 错误结构

错误响应包含稳定 `code` 和安全中文 `message`，不向界面暴露堆栈或内部连接信息。至少覆盖：

- `POINT_OUTSIDE_COVERAGE`
- `INVALID_MODE`
- `INVALID_DURATION`
- `VALHALLA_UNAVAILABLE`
- `SPATIAL_DATA_UNAVAILABLE`
- `ANALYSIS_TIMEOUT`

## 7. 离线数据产物

### 7.1 人口数据

ACS 属性与 Census tract 边界按 `GEOID` 关联。人口密度按下式计算：

`人口密度 = tract population / (ALAND / 1,000,000)`

单位为人/平方公里。生成简化后的湾区 tract 人口密度 GeoJSON 供前端着色；PostGIS 保留用于分析的完整几何和属性。

### 7.2 设施数据

从 California OSM PBF 提取并映射：

- 教育：学校、幼儿园、学院、大学等。
- 医疗：医院、诊所、医生、药房等。
- 日常购物：超市、便利店、市场等。
- 公园绿地：公园、花园、公共休闲绿地等面要素。
- 公共交通站点：公交站、轨道站和公共交通站台等。

点、线、面来源保留 OSM 类型和 ID。非公园面设施使用稳定的面内代表点参与圈内判断；公园以与步行圈相交后的有效面积计量。重复站点按规则化名称和空间邻近规则清洗，原始标识保留用于追溯。

### 7.3 清单和元数据

路由图、数据库导入文件、人口密度 GeoJSON 和评分基准必须记录：

- 来源 URL 或源文件。
- 数据日期和生成时间。
- 文件数量、记录数量和空间范围。
- 文件大小和 SHA256。
- 生成脚本版本及主要参数。

## 8. 人口估算与评分口径

### 8.1 圈内人口

15 分钟步行圈与 tract 相交后，按土地面积比例估算圈内人口：

`圈内人口 = Σ(tract population × 相交土地面积 / tract 土地面积)`

该方法假设 tract 内人口均匀分布。界面必须展示这一限制和 ACS 数据年份。

### 8.2 原始供需指标

- 教育、医疗、日常购物、公共交通站点：圈内去重设施数量/每千名估算居民。
- 公园绿地：圈内相交公园面积（公顷）/每千名估算居民。
- 原始设施数量、公园面积和圈内人口始终展示。

圈内估算人口低于 100 时，返回原始供给并标记“样本不足”，不生成分项或综合分数，防止低分母放大结果。

### 8.3 湾区相对基准

1. 为每个湾区 tract 生成一个位于有效路网附近的代表点。
2. 对每个代表点生成同口径 15 分钟步行圈。
3. 计算五类原始供需指标。
4. 以 tract 人口作为参考样本权重，建立五类经验分布。
5. 选点指标在对应经验分布中的人口加权百分位即为 0–100 分项分数。

分项 72 分表示该指标高于约 72% 的湾区居民加权参考样本，不表示达到某项公共服务标准。

### 8.4 综合指数

默认五类等权。前端对已启用且权重大于零的分类重新归一化：

`综合指数 = Σ(分项分数 × 分类权重) / Σ(分类权重)`

综合指数是多个百分位分数的加权平均，本身不称为百分位。全部分类关闭、权重总和为零或任一必要分项处于样本不足状态时，不生成综合指数并显示原因。

## 9. 交互和图层行为

1. 用户点击地图设置起点，或拖动标记更新起点。
2. 通勤分析根据当前模式和时间请求 `/gis/isochrone`。
3. 设施分析独立请求 `/gis/site-analysis`，始终使用 15 分钟步行模式。
4. 切换通勤模式或分钟数不触发设施分析。
5. 修改设施开关或权重只在前端重算综合指数。
6. 切换底图只更新样式，不触发任何分析请求。
7. 人口密度和设施图层可分别开关，并有单位、数据年份和颜色图例。

## 10. 局部降级与运行状态

- Valhalla 不可用：保留底图、人口密度和控件；禁用等时圈及依赖它的设施分析，显示“路网分析服务未就绪”。
- PostGIS 不可用：通勤等时圈仍可使用；设施统计和评分不可用。
- 人口密度 GeoJSON 不可用：关闭人口图层，不影响路由和其他地图功能。
- 点位越界或无可关联路网：保留标记，提示重新选点。
- 公共交通：控件可见但不可选，标注“建设中”。
- 连续请求：只接受最新起点和参数对应的响应。
- 权重无效：保留分项和原始数据，综合指数显示“未计算”。

健康检查分别报告 API、Valhalla、PostGIS、人口密度产物和评分基准状态。单个依赖失败不能把整个页面替换为错误页。

## 11. 测试设计

### 11.1 数据测试

- ACS 与 Census tract 的 `GEOID` 关联完整性、唯一性和人口总量核对。
- 几何有效性、坐标系、空间范围和 `ALAND` 单位验证。
- 五类 OSM 标签映射、设施去重、代表点和公园相交面积固定样例。
- 评分基准的可重复生成、记录数量、分布单调性和 SHA256。

### 11.2 后端测试

- 模式、时间、坐标边界和错误结构单元测试。
- 使用替身验证 Valhalla/PostGIS 调用边界和局部失败行为。
- 使用真实本地 Valhalla 验证步行与驾车结果不同，且等时圈不是圆形占位。
- 使用真实 PostGIS 验证人口、设施、公园面积和低人口保护。
- 验证服务失败时绝不返回圆形缓冲区。
- 本机服务就绪后，单次等时圈和选点评估目标响应时间均不超过 5 秒；首次路由图构建和数据导入不计入查询耗时。

### 11.3 前端测试

- 三种底图切换及分析图层恢复。
- 点击、拖动、快速连续操作和旧请求取消。
- 模式、时间、公共交通禁用状态。
- 分类开关、权重归一化、零权重、低人口和局部错误状态。
- lint、生产构建和关键交互测试。

### 11.4 模拟用户验收

1. 验证 3000、8000 及依赖端口的 PID 和命令行归属后，仅启动本项目服务。
2. 在失效外网代理下访问应用，确认所有浏览器请求仅指向本机。
3. 切换三种底图并检查交通网和人口密度图例。
4. 对同一点分别运行步行、驾车及四个时间档位。
5. 开启五类设施，检查原始供给、分项分数和综合指数。
6. 调整分类开关和权重，确认不重新请求空间分析。
7. 分别停止 Valhalla 和 PostGIS，确认页面局部降级且地图、起点和控件保留。
8. 保存桌面端和移动端截图。
9. 验收后只停止本轮确认归属的进程。

## 12. 实施边界与顺序

后续实施计划应按可独立验证的顺序拆分：

1. 构建人口、设施和基准数据产物。
2. 构建并验证 Valhalla 路由图及 PostGIS 导入。
3. 实现 FastAPI 配置、等时圈和选点评估接口。
4. 实现三种底图、图层控制、选点和分析面板。
5. 完成真实服务集成、断网、异常降级和截图验收。

每一阶段只修改其直接涉及的文件，不启动或停止相邻项目服务。业务实现开始前必须先形成详细实施计划并再次取得用户明确同意。

## 13. 已知限制

- OSM 设施完整度和更新时间在不同区域不一致，缺失设施会影响相对分数。
- ACS tract 内人口均匀分布是假设，不能替代街区级人口栅格。
- 驾车结果不含实时拥堵、停车搜索和末端步行。
- 公共交通站点数量不代表班次、运力或服务质量。
- 公共交通等时圈尚未实现。
- 相对分数只适用于当前湾区数据版本；数据更新后需要重建全部参考分布。
