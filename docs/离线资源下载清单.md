## 5. 完整性验证

manifest JSON、路径唯一、`artifacts` 的 23 个文件存在性、大小和 SHA256 可用 PowerShell 7 校验；上述 `database_snapshots` 不由这段文件循环伪装或代替。

```powershell
$root = "E:/HomeOrbit"
$manifest = Get-Content -Raw -LiteralPath "$root/data/offline-assets-manifest.json" | ConvertFrom-Json
$paths = @($manifest.artifacts.path)
if (($paths | Sort-Object -Unique).Count -ne $paths.Count) {
  throw "manifest 存在重复 path"
}
foreach ($item in $manifest.artifacts) {
  $file = Get-Item -Force -LiteralPath "$root/$($item.path)" -ErrorAction Stop
  if ($file.Length -ne $item.bytes) { throw "大小不匹配: $($item.path)" }
  $hash = (Get-FileHash -Algorithm SHA256 -LiteralPath $file.FullName).Hash
  if ($hash -ne $item.sha256) { throw "SHA256 不匹配: $($item.path)" }
}
"manifest artifacts verified: $($paths.Count)"
```

Protomaps 目录树另按 manifest 的 `tree_hash_format` 计算；当前为 773 文件、11,135,784 B。

PMTiles Range 需在 Web 已由主控制器确认归属并启动后验证：

```powershell
curl.exe -sS -D - -o NUL `
  -H "Range: bytes=0-126" `
  "http://127.0.0.1:3000/tiles/bay-area.pmtiles"
```

预期为 `206 Partial Content` 和 `Content-Length: 127`。这属于真实服务验收，不由静态 manifest 校验代替。
